# C++ Calculator (Code::Blocks starter)

Code::Blocks C++ console project scaffold for a calculator program.

## Status

The project currently contains the Code::Blocks starter template (`main.cpp` prints "Hello world!"). The working calculator lives in [cpp-calculator](../cpp-calculator).

## Build

Open `calculator c++.cbp` in Code::Blocks, or:

```bash
g++ main.cpp -o app
```
